## 🚀 Overview

**HireMind AI** is an intelligent resume analysis platform designed to help students, freshers, and professionals create stronger resumes.

Simply upload your resume, and the AI analyzes its content, structure, skills, ATS compatibility, and overall quality. It then provides actionable suggestions to improve your chances of getting shortlisted.

Whether you're applying for internships, SDE roles, or experienced positions, HireMind AI helps you build a resume recruiters actually want to read.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/HireMind-AI.git
```

```bash
cd HireMind-AI
```

---

### Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

---

### Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection

JWT_SECRET=your_secret_key

OPENAI_API_KEY=your_openai_api_key

CLOUDINARY_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_SECRET=
```

---

### Run the Application

Backend

```bash
npm run dev
```

Frontend

```bash
npm start
```

## 💡 How It Works

1. Upload your resume.
2. The resume is parsed and processed.
3. AI analyzes:
   - Resume content
   - Skills
   - ATS compatibility
   - Formatting
   - Missing keywords
4. Receive:
   - ATS Score
   - Detailed feedback
   - Personalized suggestions
   - Resume improvement tips
